# WealthTools — passive income playbook

`wealth-tools.html` is a single-file, zero-dependency financial calculator hub
(compound interest, dividend income, FIRE, rental ROI, savings goal). Finance
calculators attract steady, high-intent search traffic and cost nothing to run,
which is what makes this a genuinely *passive* income project.

## 1. Deploy for free (5 minutes)

**GitHub Pages:** repo → Settings → Pages → deploy from `main`. Rename the file
to `index.html` (or link to it) and the site is live at
`https://<user>.github.io/<repo>/`.

Alternatives: Netlify or Cloudflare Pages (drag-and-drop the file). A custom
domain (~$10/yr) significantly helps SEO and AdSense approval.

## 2. Monetize

1. **Google AdSense** — apply once the site is on a custom domain. Paste ad
   units into the two placeholder `div.adslot` blocks (search the HTML for
   `AD SLOT`). Finance is one of the highest-RPM niches.
2. **Affiliate links** — the "Ready to put the numbers to work?" card (id
   `affiliate`) has three slots for broker / high-yield savings / real-estate
   platform referral links. Finance affiliate payouts commonly run $10–$100+
   per signup.
3. Keep the affiliate disclosure line — it's legally required in most markets.

## 3. Get traffic

- The page already ships with SEO meta tags, JSON-LD schema, and long-form
  keyword copy at the bottom. Submit the site to Google Search Console.
- Each calculator has a **Copy shareable link** button — shared parameterized
  links (e.g. `?tab=fire&fi-age=25`) are free distribution on Reddit
  (r/personalfinance, r/Fire, r/dividends), forums, and social.
- Optional growth: add one calculator page per niche keyword over time
  ("401k calculator", "crypto DCA calculator", …) — each is a new search entry
  point.

## Disclaimer

The calculators are educational estimates, not financial advice — the page
says so in the footer. Keep that disclaimer if you modify the site.
